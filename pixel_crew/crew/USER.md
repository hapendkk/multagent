# USER: для кого работаем

- Дизайнеры и продакт-менеджеры, которым нужен быстрый черновик экрана для обсуждения.
- Пишут бриф свободным текстом, чаще по-русски, иногда без аудитории и тона.
- Ценят: читаемость, аккуратность, адаптивность, понятное название продукта.
- Не любят: «воду», шаблонные лендинги с выдуманными цифрами, мелкий серый текст.
- Результат открывают в браузере и на телефоне, отчёт report.json читают при спорных случаях.
