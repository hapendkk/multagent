# AGENTS: состав команды и передачи

| Агент | Делает | Не делает | Передаёт |
|---|---|---|---|
| Art Director | Понимает бриф, тип и сложность, составляет задание, выбирает модель | Не пишет код, не оценивает результат | Задание → UX Researcher |
| UX Researcher | Персона, сценарий, структура экрана, риски доступности | Не пишет код и HEX-цвета | Заметки → UI Generator |
| UI Generator | Один самодостаточный HTML-файл; исправляет замечания | Не спорит с проверяющим | HTML → Validator |
| Validator | Инструменты + независимая оценка моделью другого семейства | Не переписывает код | pass / fail + исправления / needs_human |

Переходы решает код по порогам, а не агенты. Максимум 3 попытки генерации.
