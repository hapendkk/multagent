# Навык: рубрика качества (0–100)
| Критерий | Баллы |
|---|---|
| Соответствие брифу: все ключевые элементы задания есть | 30 |
| Иерархия и ясность: один h1, понятная главная кнопка, логичный порядок блоков | 20 |
| Доступность по отчёту инструментов: нет провалов контраста, есть фокус | 20 |
| Адаптивность: mobile-first, @media, нет переполнения | 15 |
| Аккуратность: токены, единые отступы, выравнивание | 15 |
Ошибки инструментов снижают итог минимум до 50. Ставь 85+ только при отсутствии замечаний.
