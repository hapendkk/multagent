# Навык: бриф → задание
- Название продукта: 1–2 слова, **один алфавит** (только латиница или только кириллица), без кавычек и эмодзи.
- Ключевые элементы: 3–6 конкретных блоков экрана, а не абстракций.
- Сложность: 0–30 — один простой блок (форма входа, карточка); 31–60 — несколько секций; 61–100 — дашборд, данные, много состояний.
- Тон — 2–3 слова («спокойный, дружелюбный»).
