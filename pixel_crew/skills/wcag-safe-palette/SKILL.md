# Навык: безопасная палитра
- Текст `#1a1a1a`–`#333` на `#ffffff`/`#f7f5f2` — ≥ 12:1. Вторичный текст не светлее `#595959` на белом (7:1).
- Белый текст только на тёмных акцентах: `#1f5f5b` (7.0:1), `#2a4d8f` (8.3:1), `#8a3a2e` (7.6:1), `#5b3b8c` (8.6:1).
- **Hover/active темнее**, а не светлее базового цвета (напр. `#1f5f5b` → `#174845`). Светлый hover — частая причина провала.
- Не используй `opacity` на тексте и не ставь текст на градиент без сплошной подложки.
- Бордеры полей ввода не светлее `#767676` на белом (3:1 для UI-компонентов).
- Все цвета — переменные в `:root`: `--bg, --surface, --text, --muted, --accent, --accent-hover, --on-accent`.
