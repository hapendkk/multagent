# Навык: лендинг
- Первый экран: название продукта, заголовок-выгода (≤ 8 слов), подзаголовок (1–2 строки), одна CTA-кнопка.
- Дальше 3 преимущества карточками (иконка CSS/SVG + заголовок + 1 фраза), затем как это работает (3 шага), затем повтор CTA.
- Без выдуманных отзывов, логотипов клиентов и цифр («10 000 пользователей»). Если нужен блок доверия — честные факты из брифа.
- Заголовок `h1` один; секции — `h2`. Крупный текст на hero — на сплошной подложке.
