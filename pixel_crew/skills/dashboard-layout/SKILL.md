# Навык: дашборд
- Сверху: заголовок + период/фильтр. Затем 2–4 KPI-карточки: подпись, крупное число, изменение со знаком и словом («+12% за неделю»), а не только цветом.
- Сетка: `grid-template-columns: repeat(auto-fit, minmax(150px, 1fr))` — на телефоне 2 колонки, на десктопе 4.
- График — inline SVG с `role="img"` и `aria-label` с выводом словами; ось и подписи — контраст ≥ 4.5:1.
- Таблица/список последних событий — в контейнере `overflow-x: auto`, на телефоне лучше карточки.
- Ширину `.app` для дашборда можно увеличить на десктопе (`max-width: 1100px` в `@media`).
- Без выдуманных «реальных» данных: подписи вида «Пример данных».
- Объём: весь файл ≤ ~9 000 символов, иначе ответ обрежется. CSS без комментариев, один общий стиль для карточек, в таблице 4–5 строк, график — одна polyline и 5 подписей оси.
