# Навык: доработка по замечаниям
1. Выпиши для себя каждое замечание и найди точное место в коде (селектор, переменная, тег).
2. Для контраста меняй значение переменной в `:root` (и её hover-вариант), а не отдельные правила.
3. Для переполнения ищи фиксированные ширины, `100vw`, отсутствие `flex-wrap`/`min-width:0`.
4. Для названия проекта вставь его ровно в том написании, что в задании, в `<title>` и в `h1`/логотип.
5. Остальной код не трогай. Верни ПОЛНЫЙ файл одним блоком ```html.
