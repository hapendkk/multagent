# Навык: формы
- У каждого поля видимый `<label for>`; placeholder — только пример, не замена подписи.
- Поля и кнопки высотой ≥ 44 px, шрифт ≥ 16 px (иначе iOS увеличивает страницу).
- Правильные `type` и `autocomplete` (`email`, `tel`, `current-password`, `one-time-code`).
- Подсказки и ошибки — текстом под полем, связаны через `aria-describedby`; ошибку не передавай только красным цветом.
- Одна основная кнопка на всю ширину на телефоне; второстепенные действия — ссылками.
- Поля в одну колонку; группы — `<fieldset>` + `<legend>`.
